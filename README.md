## Chateo
A real-time chat application enabling one-on-one messaging using Firebase as the backend.

## 🚀 Getting Started

To run this project on your local machine:

```bash
# Clone the repo
git clone https://github.com/ykabdelrahman/chateo.git
cd chateo

# Get dependencies
flutter pub get

# Run the app
flutter run
```
